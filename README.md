# data-science-data-cleaning-plant-based-coffee-shop
Data cleaning and exploratory data analysis (EDA) project using Pandas on a survey dataset of ~1,000 coffee enthusiasts. The analysis identifies the most preferred dairy and plant-based milk choices to help a specialty coffee shop decide which dairy alternatives to stock for a fully plant-based beverage menu.

## Data Sources:

Data comes from the Great American Taste Test by James Hoffmann.

The data is found at:
https://jameshoffmann.co.uk/s/GACTT_RESULTS_ANONYMIZED_v2.csv
